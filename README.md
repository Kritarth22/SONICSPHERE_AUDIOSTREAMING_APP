# SONICSPHERE_AUDIOSTREAMING_APP
Developed a music streaming database system with tables for Users, Artists, Albums, Tracks, Playlists, Podcasts, Subscriptions, and Social Activity. Designed and implemented ER diagrams, relational schemas, normalization (up to BCNF), DDL scripts, and SQL queries to manage complex relationships and maintain data consistency.

Worked on junction tables like PlaylistTracks and features such as user follows, interactions, and subscriptions to simulate real-world streaming platform functionality.

Key Learnings: Database design, ER modeling, normalization, SQL queries, and handling complex relational data structures.

Favorite Part: Designing playlist, follower, and interaction systems, which gave practical insight into how platforms like Spotify manage large-scale user data and relationships.
